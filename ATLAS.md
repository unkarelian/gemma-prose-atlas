# Prose atlas: Gemma 3 4B-it

720 transcoder features (Gemma Scope 2, 34 layers x 16,384) that fire differently for different writers of the same brief, attach to a prose construction, or write toward one of Gemma's habitual tokens. Labels were written by Claude from each feature's examples, firing rates and output tokens; they are best guesses with a confidence level.

The interactive version is `site/atlas.html` (clone the repo and open it in a browser; it needs `site/assets/`). The same data as JSON is `results/atlas.json`.

Columns: **G / H / L** = share of text tokens the feature fires on in Gemma's, human and other-LLM stories (r/WritingPrompts, same prompts), in percent.
